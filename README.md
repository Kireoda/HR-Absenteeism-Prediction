
# HR Absenteeism Prediction

## Project Overview
This project focuses on workforce management within the Human Resources (HR) domain. It uses data analytics and predictive modelling to analyse employee absenteeism and identify patterns that may help organisations improve workforce planning and decision-making.

## Business Problem
Employee absenteeism can contribute to understaffing, increased workload for other employees, reduced productivity, and increased operational costs.

The aim of this project is to analyse historical absenteeism data and develop a predictive model to support workforce management decisions. This project is for the Data Science Continuous Assessment 2

## Objectives
- Collect and prepare relevant workforce data.
- Analyse absenteeism patterns and relationships between variables.
- Identify relevant features for predictive modelling.
- Develop and evaluate predictive models.
- Generate insights and recommendations to support HR decision-making.
